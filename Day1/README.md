# AI Agent Day 1: Chatbot vs Workflow vs AI Agent

## Project Overview

This project demonstrates three different approaches to solving the same student task-management problem:

1. Plain Chatbot
2. Rule-Based Workflow
3. AI Agent

The scenario is a Student Personal Task and Assignment Assistant.

The system answers:

> What tasks do I have due soon, and which one should I work on first?
